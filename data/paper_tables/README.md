# Paper Tables

JSON values transcribed from Tables 2 and 9-12 of the supplied paper. The source PDF SHA-256 and page are recorded in each file. Percentages, percentage-point changes, raw Edge F1 changes, issue counts, and mean token changes use the units in their field names.

Table 9 outcome counts sum to 300. Table 2 aggregate FC and PV changes use 300 paired records. Table 11 outcome changes are net issue counts; token changes are per-issue means. Table 12 stores favorable category counts and their denominators.
